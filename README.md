# Analytics Copilot

Небольшой аналитический дашборд со стримящим AI-ассистентом поверх него. Смотришь на график выручки, фильтруешь по категории и задаёшь вопросы о том, что видишь, в чат-панели — ответ приходит токен за токеном, так же как ответы ChatGPT/Claude.

> **Статус:** 🚧 начальный скелет — этот README сейчас является спецификацией, кода ещё нет. Первый реальный коммит.

## Зачем этот проект

Большинство "дашбордов для портфолио" — это просто график и больше ничего. Этот сочетает две вещи, которые постоянно встречаются в реальной фронтенд-работе и почти никогда не встречаются вместе в учебном проекте:

- **Типизированная, протестированная визуализация данных** — не просто "график рисуется", а график, чья функция преобразования данных покрыта юнит-тестами, и чьи граничные случаи (пустые данные, неотсортированный вход, одна и та же ссылка для мемоизации) учтены.
- **Правильно сделанный стриминг LLM-ответов** — Server-Sent Events, разобранные с корректной буферизацией на границе сетевых чанков, отмена через `AbortController`, когда пользователь задаёт новый вопрос до того, как долетел старый ответ, и отсутствие тихих бесконечных циклов на некорректном вводе. Это как раз то, что большинство туториалов пропускают или делают с тонкими ошибками.

## Стек

- **React 18 + TypeScript** (`strict`, `noUncheckedIndexedAccess`)
- **Vite** — дев-сервер, сборка, алиасы путей, типизация env-переменных
- **Recharts** — рендер графиков
- **MSW** (Mock Service Worker) — замоканный бэкенд и для тестов, и для локальной разработки, включая реалистичный SSE-стриминг-эндпоинт; в будущем заменяется на настоящий API
- **Vitest + React Testing Library** — поведенческие тесты, не снэпшоты
- **ESLint 9 (flat config) + Prettier** — typescript-eslint, react-hooks, `eqeqeq`, форматирование при сохранении
- **GitHub Actions** — typecheck → lint → test на каждый push/PR

## Планируемые фичи (MVP)

- [✓] График выручки, агрегированный по месяцам из сырых записей заказов
- [✓] Фильтр по категории, производные данные через `useMemo`
- [✓] Чат-панель, которая стримит ответы о текущих отфильтрованных данных
- [✓] Отмена запроса: смена фильтра или новый вопрос посреди стрима не дают устаревшему ответу перезаписать свежий
- [ ] Code-splitting чат-панели (`React.lazy` + `Suspense`), чтобы она не попадала в начальный бандл
- [ ] Зелёный CI на GitHub Actions (typecheck, lint, test)
