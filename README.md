# Analytics Copilot

Аналитический дашборд со стримящим AI-ассистентом поверх него. Смотришь на график выручки, фильтруешь по категории и задаёшь вопросы о том, что видишь, в чат-панели — ответ приходит токен за токеном, так же как ответы ChatGPT/Claude, с полным контекстом текущего отфильтрованного срез данных и всей истории диалога.

> **Статус:** ✅ готово — MVP реализован, зелёный CI (typecheck, lint, FSD-линт, тесты).

## Зачем этот проект

Большинство "дашбордов для портфолио" — это просто график и больше ничего. Этот сочетает две вещи, которые постоянно встречаются в реальной фронтенд-работе и почти никогда не встречаются вместе в учебном проекте:

- **Типизированная, протестированная визуализация данных** — агрегация заказов по месяцам через `Map` (не `O(n·m)` поиск), покрыта юнит-тестами на граничные случаи (пустые данные, неотсортированный вход, немутирующий вход, производительность на 200k записей).
- **Правильно сделанный стриминг LLM-ответов** — Server-Sent Events, разобранные собственным `readSSEStream` (async-генератор) с корректной буферизацией на границе сетевых чанков и поддержкой `\r\n\r\n`-разделителя, отмена через `AbortController` при новом вопросе или смене фильтра посреди стрима, явная обработка HTTP-ошибок и обрыва потока без финального `[DONE]` — вместо тихого бесконечного `"pending"`.

## Архитектура

Feature-Sliced Design (`app` → `pages` → `widgets` → `features` → `entities` → `shared`), линтуется через [Steiger](https://github.com/feature-sliced/steiger) (`npm run lint:fsd`) с точечными исключениями под реальные паттерны проекта (`app/providers` как сегмент, `insignificant-slice` понижен до warning — осмысленно для текущего размера, не глушит настоящие нарушения направления импортов и сайдстепы публичного API).

- `entities/order` — модель заказа, агрегация по месяцам, фильтр по категории.
- `features/filter-orders-by-category` — контролируемый фильтр категории.
- `features/stream-chat-answer` — `useLLMStreaming` (хук стриминга), `readSSEStream`/`parseLLMAnswer` (разбор SSE и валидация формы ответа через type guard, без сторонних схем-валидаторов).
- `features/current-date` — живые часы в заголовке.
- `widgets/chat-panel` — композиция чата: история диалога, живой "печатающийся" ответ, лениво подгружается (`React.lazy` + `Suspense`), не попадает в начальный бандл.
- `widgets/revenue-chart` — график на Recharts.
- `pages/dashboard-page` — сборка всего вместе.
- `shared/ui` — `Select`, `Input`/`Textarea`, `IconButton`, `Title`/`Paragraph`, `Loader`, `ErrorBoundary` — переиспользуемые примитивы, без бизнес-логики.

## LLM-бэкенд

Вместо платного облачного API (недоступного из РФ без посредников) — локальная модель через [Ollama](https://ollama.com), OpenAI-совместимый `/v1/chat/completions` эндпоинт со стримингом:

```bash
brew install ollama
ollama pull llama3.2:3b
OLLAMA_ORIGINS="http://localhost:5173" ollama serve
```

Бесплатно, без ключей, без сетевых ограничений — SSE-формат ответа идентичен реальным облачным API, так что вся логика парсинга/стриминга переносится на них без переписывания.

## Стек

- **React 19 + TypeScript** (`strict`, `noUncheckedIndexedAccess`)
- **Vite 8** — дев-сервер, сборка, алиасы путей (`vite-tsconfig-paths`)
- **React Router** — маршрутизация
- **Recharts** — рендер графиков
- **Vitest + React Testing Library** — поведенческие тесты (через `render`/`screen`/`fireEvent`, `renderHook` для хуков), не снэпшоты
- **ESLint 9 (flat config) + Prettier** — typescript-eslint, react-hooks (включая `set-state-in-effect`/`exhaustive-deps`), форматирование при сохранении
- **Steiger** — линт границ FSD-слоёв
- **GitHub Actions** — typecheck → lint → lint:fsd → test на каждый push/PR

## Реализованные фичи

- [x] График выручки, агрегированный по месяцам из сырых записей заказов (`Map`, O(n))
- [x] Фильтр по категории, производные данные через `useMemo`
- [x] Чат-панель, которая стримит ответы о текущих отфильтрованных данных и всей истории диалога
- [x] Отмена запроса: смена фильтра или новый вопрос посреди стрима не дают устаревшему ответу перезаписать свежий
- [x] Обработка HTTP-ошибок модели и обрыва стрима без `[DONE]` — без зависания в `"pending"`/`"streaming"`
- [x] Code-splitting чат-панели (`React.lazy` + `Suspense`), чтобы она не попадала в начальный бандл
- [x] Zod-less валидация формы ответа LLM через ручной type guard
- [x] Зелёный CI на GitHub Actions (typecheck, lint, FSD-линт, test)

## Как запустить

```bash
# Node 22+ обязателен (.nvmrc)
nvm use

npm install

# в отдельном терминале — локальная модель
OLLAMA_ORIGINS="http://localhost:5173" ollama serve

npm run dev           # http://localhost:5173
npm test              # Vitest + RTL
npm run test:coverage
npm run typecheck
npm run lint
npm run lint:fsd
```
